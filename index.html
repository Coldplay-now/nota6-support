Nota6

Markdown reader for the AI era · macOS

Nota6 is a read-only Markdown previewer for macOS, designed for the moment when AI tools like Cursor, Claude Code, and Copilot generate piles of .md files that need to be read, not edited.

  • Double-click a .md and see a fully rendered page within ~300ms
  • Mermaid diagrams · KaTeX math · syntax-highlighted code, all bundled locally
  • Auto-refresh when the file changes outside
  • Folder browsing for project docs/ directories
  • ⌘P quick switcher across files in the workspace
  • Sandboxed, signed, no telemetry
  • English + 简体中文
