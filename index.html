Nota6

Markdown reader for the AI era · macOS

Version 1.2.1 · macOS 14.0+

Nota6 is a read-only Markdown previewer for macOS, designed for the moment when AI tools like Cursor, Claude Code, and Copilot generate piles of .md files that need to be read, not edited.

What 1.2 ships

Read fast

  • Double-click a .md → fully rendered page within ~300ms
  • Mermaid · KaTeX · highlight.js bundled offline, zero network for rendering
  • 4 themes (GitHub / Paper / Notion / Terminal), 4 font sizes, 3 reading widths
  • Per-file scroll position persistence
  • Outline panel (⌥⌘O) with scroll-synced highlight
  • Immersive mode (⌘.) hides all chrome
  • Mermaid click-to-zoom modal

AI workflow

  • Auto-refresh on file change (file watcher)
  • Amber flash when content updates externally — see at a glance what AI just rewrote
  • Workspace folder browsing with ⌘P quick switcher
  • Workspace-wide full-text search (⌘⇧F)
  • Internal Markdown links jump within Nota6

Share / export

  • Copy as Rendered (HTML + RTF + Plain — paste into Slack / Notion / email with formatting)
  • Save selection as PNG (2× retina)
  • Paginated PDF export, self-contained HTML export

System reach

  • QuickLook preview plugin (Finder spacebar uses Nota6's renderer)
  • nota6 CLI: nota6 file.md / nota6 docs/
  • URL scheme: nota6://open?path=...
  • Set as default .md app from the welcome screen
