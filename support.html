Common questions

Why doesn't Nota6 let me edit?

By design. Nota6 is a Markdown reader. Use your IDE or a dedicated editor (Typora, iA Writer, Obsidian) to write Markdown, and use Nota6 to read it.

My file isn't refreshing automatically

Make sure "Auto refresh on file change" is enabled in the toolbar's ⋯ menu. If your editor writes to a temp file and renames it (vim, some editors), Nota6 handles that transparently.

The folder I picked has no files in the sidebar

Nota6 only displays Markdown files (.md / .markdown / .mdx) and hides empty directories. Some common build/cache directories (node_modules, .git, build, etc.) are always skipped.

Mermaid diagram is too small

Click on the diagram to enlarge it (coming in a near update).

Where are my recent files / preferences stored?

In your standard macOS user defaults. They never leave your Mac. See privacy policy.
